## Project structure

```
portfolio/
├── index.html    Page structure and content
├── style.css     Styling (layout, colours, fonts, dark mode)
├── script.js     Interactive features (optional)
└── README.md     Project documentation
```

## Tech stack

- HTML5
- CSS3 (custom properties, grid, flexbox, responsive design)
- Vanilla JavaScript
- Google Fonts

No frameworks, build tools or installs are needed.

## Features

- Responsive layout for mobile, tablet and desktop
- Light and dark mode that follows the device setting
- Case study sections with problem, process and result
- About, skills and contact sections
- Accessible markup with visible keyboard focus

## Getting started

1. Download or clone this repository.
2. Keep all files in the same folder.
3. Open `index.html` in your browser.

Optional: use the VS Code Live Server extension for automatic reload.

## Customisation

| What to change | Where |
|----------------|-------|
| Name, text, links | `index.html` |
| Colours and fonts | Variables at the top of `style.css` |
| Case study images | Add files to an `images/` folder and reference them in `index.html` |
| Behaviour | `script.js` |

## Deployment

- Netlify Drop: https://app.netlify.com/drop
- GitHub Pages: Settings, then Pages, then choose the main branch
- Vercel: import the repository

## Case studies

For each project, include:

1. Problem: what was not working for users
2. Role: what you were responsible for
3. Process: research, wireframes, prototypes, testing
4. Result: a real, measurable outcome
5. Screens: final designs and Figma link
